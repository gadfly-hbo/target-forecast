### V4 计算与比较(`stage=3`)

头:`比较结果,判断目标缺口` + 徽标 `演示计算`(生产按 D5 换为真实引擎标识)。

## 12. 禁止路径/状态(Negative cases,REVIEW 红线)

1. 过期结果被保存为当前运行(按钮禁用 + 模型层抛错双重拦截)。
2. AI 未配置/回放/失败显示成已执行成功或真实模型能力(A15)。
3. 新 UI 嵌入旧 workbench iframe 形成双 chrome(D5)。
4. localStorage 作为正式业务存储(D5/G3)。
5. 原始订单明细进入模型上下文(D6/G3)。
6. 过期提案覆盖更新的工作稿(修订绑定,禁用 + 拒绝)。
7. 放弃提案产生任何变更(零变更)。
8. 同内容重复保存增生新版本/新运行(幂等去重)。
9. 导出读到「最近一次 output」而非指定运行;导出失败撤销已保存运行或声称未保存。
10. 计算失败/取消写入半结果;恢复时盲目重复执行(先查状态)。
11. 无 UV 时编造 UV 或把缺失当 0(US9)。
12. 把业务假设/AI 建议标成已验证事实;采用某档自动宣称推荐(US12/US17)。
13. 未保存表单被切页/AI 动作/刷新静默丢失(脏表单保护 + beforeunload)。
14. 工作稿修改改变已保存运行的快照与下载内容(A11)。
15. demo-only 元素(方案.html 外链、重置演示、workflow-note、原型标签)出现在生产界面(G9)。
16. 未实现的执行器返回假成功(G2 兜底 raise/422)。
17. 页面级横向溢出(390px 表格只许容器内滚动)。

## 13. 状态语义(六态分别可见,非单个大绿灯)

| 状态 | demo 可见位置 | 生产落点 |
|---|---|---|
| 工作稿已保存 | 页头元信息 `已保存到本浏览器 · r{N}`;失败时 `未能持久保存` + storage warning 横幅 | 服务端持久化成功标识;失败同样显式(D5) |
| 口径已确认 | V2 徽标 `口径已确认`/`待确认口径` + checkbox | 同位;数据/口径变更后失效回待确认(D2/G4) |
| 假设已确认 | V3 徽标 `已确认用于试算`/`待确认用于试算` + checkbox | 同位;三域变更失效(D2/G14) |
| 计算完成 | V4 结果区出现 + toast `三档情景已计算,尚未保存为运行`;V5 方案状态 `已有有效计算` | job done;done-未保存带 `未保存` 标记(G3) |
| 运行已保存 | V5/S4 运行列表 + 侧栏计数 + toast `已保存 v{N}.0 · {RUN}` | 同位;`run_id` 仅 save 成功铸造(G3) |
| 文件已导出 | toast `已发起下载:{RUN} 的保存结果` | 同位 + 运行导出记录(失败显式可重试,G8) |

过期不是删除:旧运行/旧导出永远可读可下载,但标注来自旧版本,不得冒充当前结果保存。
