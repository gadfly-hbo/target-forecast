## 0. 定位与核心决策

**产品定位**：独立运行的满减券方案测算与比较工具，帮助业务人员判断"是否发券、满多少减多少、需要多大转化提升才能回本，以及结论对哪些假设敏感"。

**核心交付闭环**：导入数据 → 设置场景 → 比较含无券基准的候选 → 查看收益拆解与假设 → 人工确认并导出 → 活动后复盘。

**必须坚持四点**：
1. 先算清账，再谈推荐。转化率、订单量、核销量、补贴与贡献收益必须来自同一组互斥结果分支。
2. 允许"不发券"成为结论。没有可行券方案时，不强行挑出"相对不差"的方案。
3. 没有因果证据，不把假设包装成预测。参数可手工设定，但来源、适用范围和敏感性必须可见。
4. 先独立交付，再预留接入。首期不依赖 JuanerAI / Xanthil Desktop、Analysis IR、Semantic Context Runtime、Domain Pack、Model Pack 或企业知识库。

**建设顺序**：先实现纯计算引擎与验收测试，再完成轻量界面和独立工作流。先独立工具，后续作为 JuanerAI 二级/三级功能接入，未来只预留 ScenarioSpec / Result / Review 三个接缝。

### 0.1 关键口径修订（相对原稿 v1，必须落实）

- 使用"本次券前、按实际券规则计算的可用商品金额"作为 A，不用"实付客单价"（防重复减券）。
- 凑单失败增加"购买流失"分支（原稿公式未计入流失）。
- q̄ 与低价格带平均客单价相乘改为逐订单/逐细分桶计算后汇总（q 与 A 相关时均值乘积≠乘积均值）。
- 对增量转化不再乘未归一化 hit，为新增成交单独指定归一化结果分布 vⱼ。
- 默认要求增量贡献 ΔΠ ≥ 0；受控亏损必须单独启用。
- 默认目标口径为**券后贡献收益**（毛利、补贴、可变费用分项展示），不用"综合毛利率"混口径。
- 原稿示例表不作为验收黄金值；新版黄金值为第七节可重跑合成案例。

## 一、P0 首期必须交付

| 模块 | 首期内容 | 完成标准 |
|---|---|---|
| 数据与基准 | 手工分桶 / CSV / 标准 XLSX 导入，字段映射，数据质量检查，无券基准设置 | 不需要接业务数据库即可完成一次测算 |
| 券与成本配置 | 单张满减券、商家承担比例 ρ、商品毛利与可变费用、预算与业务约束 | 券规则与成本口径可保存并复用 |
| 行为情景 | 核销、凑单、失败流失、新增转化与新增篮子假设 | 每个参数有来源标签，无隐式"行业真值" |
| 计算与比较 | 无券 + 候选组合、统一收益账本、约束过滤、敏感性、盈亏平衡 | 表格与决策卡来自同一计算结果 |
| 确认与导出 | 人工选择，导出 Markdown 决策摘要、CSV 明细、JSON 运行记录 | 能解释选了什么、为什么、当时假设是什么 |
| 轻量复盘 | 导入实际汇总值，预测与实际对比，记录偏差原因，人工建立参数新版本 | 原结果保留，不自动覆盖历史参数 |
| 本地与重跑 | 项目保存、输入快照、配置版本、引擎版本、运行 ID | 同一输入与版本得到相同结果 |

### 1.4 明确不做（首期）

不做：自动发券、券投放接口、实时竞价、实验分流平台、实时风控、按人个性化优惠、多券竞争与叠加优化、自动训练响应模型、自动更新经营规则、承诺销量或利润、精美 PPT / PDF 排版、小时级监控、线上切券、自动告警、固定 90/10 分流。

首期的"模型"主要是可解释的规则与情景计算，不要求先训练机器学习模型。

## 二、总体框架

保留 L1 输入层、L2 测算层（四个子模型）、L3 决策层，补齐产品闭环（比较/解释/确认/导出/复盘 + 本地存储 + 质量治理）。

| 子模型 | 输入 | 输出 | 不得承担的职责 |
|---|---|---|---|
| ① 命中与核销 | T、F、券可用金额、触达与核销假设 | 自然命中标记、可核销状态、分支概率 | 不把"达到门槛"直接等同于"实际核销" |
| ② 凑单与流失 | 门槛缺口、可加购金额、凑单与流失参数 | 加购成交、原样成交、放弃购买分支 | 不把所有凑单失败都当作保留成交 |
| ③ 转化响应 | C₀、新增转化情景、新增订单分布 | 新增成交数量、最终转化率 | 不把净转化提升重复作为毛新增量计入 |
| ④ 统一收益账本 | 各成交分支、商品毛利、补贴、费用 | 订单、成交金额、补贴、贡献收益、增量 | 不重新生成一套与转化率不一致的订单权重 |

串行接口用于控制依赖与核对结果；实现可向量化，不要求四次独立扫描。

## 三、L1 输入层规格

- **观察单位**：固定活动观察窗口内每观察单位最多计一笔符合条件的支付订单；可选"去重用户"或"会话"，但 N、C₀、实际结果与实验数据中必须同口径，不能混用；订单数不能直接当购买用户数。需要同一用户多次购买时改订单率/复购模型。
- **输入三档**：只有金额分布 → 情景结果（缺 N 不输出活动总量）；有 N、C₀ 但行为靠假设 → 完整比较+预算+盈亏平衡+敏感性，标记"假设情景"，不伪造置信区间；有对照/实验 → 注明来源的估计值+适用范围。
- **必需字段与缺失处理**：`observation_unit`/`window`（缺失阻断全量转化测算）；N（可降级到每单位结果）；C₀（不从有券订单表反推，可显式假设）；Aᵢ、wᵢ（wᵢ≥0 合计=1，不得当作全部访问者的意向篮子分布）；原商品毛利（粗粒度毛利率标记为估算）；加购商品毛利（不默认等于原商品，可相等但需显式确认）；券承担比例 ρ（未确认不得默认平台承担）；其他费用（履约/支付平台费/退货净影响/增量固定费用，标明已含/单列/忽略/未知）；行为参数（无来源只能作情景输入）。
- **金额基准**：A 使用本次券尚未扣减、符合实际门槛规则的商品金额，不含运费；其他优惠必须按明确规则折入基准且在所有候选间不变；混合可用/不可用商品、复杂叠加、特殊平台门槛算法不满足假设时**阻断**或专用规则适配，不静默近似。能重建券前金额≠重建无券反事实。
- **分布处理**：经验分布/分位数优先，对数正态拟合仅作可选近似；分桶保留桶内平均券前金额与毛利；门槛穿过粗桶且无法确定桶内分布时给上下界或要求细分，不用桶中点伪造精确命中率。
- **候选门槛**：可从 P40/P50/P60/P70/P75 出发 + 人工增补；尾数 9 是可选业务候选规则不是默认心理学结论；取整后真实门槛必须重新计算；候选设金额上下界与数据适用范围，超出历史支持标"外推情景"。
- **基准版本与数据质量**：保存来源、样本窗口、活动类型、适用人群、品类范围、历史促销状态、金额口径与成本口径；日常数据代理大促标"场景不一致"，通过情景变化处理，不自动套固定下移比例。至少检查：空值、重复订单、A≤0、非法概率、权重不守恒、货币单位混杂、成本重复扣减、退款单未说明、流量与订单窗口不一致、触达率重复计算、历史券后金额误用。

## 四、L2 测算层公式（引擎核心规格）

### 4.1 统一符号

T、F（门槛与面额，P0 有效券要求 0<F<T）；Aᵢ、wᵢ（基准成交篮子金额与条件权重，Σwᵢ=1）；eᵢ（基准成交人群中实际可见且可使用本次券的比例）；rᵢ、rᵢ⁺（自然达标后核销概率、加购达标后核销概率）；qᵢ（已触达且原本未达门槛者加购达标概率）；dᵢ（未加购达标者中因券场景放弃原本购买的概率）；Bᵢ（加购后本次券前金额，Bᵢ≥T）；ΔC⁺（相对全部 N 的毛新增成交概率，未扣流失）；vⱼ（新增成交订单各结果类型权重，Σvⱼ=1）；u（分支是否核销，0/1）；ρ（商家实际承担比例）；π、Π、ΔΠ（单笔贡献、活动总贡献、相对无券增量贡献）。

### 4.2 子模型①：命中与核销

```text
自然命中权重 P₁ = Σᵢ wᵢ · I(Aᵢ ≥ T)
需凑单权重 P₂ = 1 − P₁
```

对 Aᵢ ≥ T 的分支（P0 简化：自然达标人群不单独估计"看到券反而流失"或超门槛继续加购）：

| 结果 | 概率 | 商品金额 | 核销 |
|---|---:|---:|---:|
| 未触达，按原计划购买 | 1−eᵢ | Aᵢ | 0 |
| 已触达并核销 | eᵢrᵢ | Aᵢ | 1 |
| 已触达但未核销，按原计划购买 | eᵢ(1−rᵢ) | Aᵢ | 0 |

### 4.3 子模型②：凑单与流失

跳档缺口 `gᵢ = (T − Aᵢ) / Aᵢ`。P0 优先"缺口档位 × 折扣强度"用户参数表；无参数表时用透明演示曲线（情景函数，非行为定律，参数可替换）：

```text
qᵢ = q_cap × exp(−λgᵢ) × min(1, (F/T) / d_ref)
```

q_cap∈[0,1]、λ≥0、d_ref>0。禁用券时直接返回无券基准，不运行券诱导行为。

对 Aᵢ < T 的完整分支（概率合计=1）：

| 结果 | 概率 | 商品金额 | 核销 |
|---|---:|---:|---:|
| 未触达，原样购买 | 1−eᵢ | Aᵢ | 0 |
| 加购达标并核销 | eᵢqᵢrᵢ⁺ | Bᵢ | 1 |
| 加购达标但未核销 | eᵢqᵢ(1−rᵢ⁺) | Bᵢ | 0 |
| 未加购达标，仍原样购买 | eᵢ(1−qᵢ)(1−dᵢ) | Aᵢ | 0 |
| 未加购达标，放弃原本购买 | eᵢ(1−qᵢ)dᵢ | 无订单 | 0 |

Bᵢ 优先来自可加购商品或经验加购金额；简化取 Bᵢ=T 时标记"恰好凑到门槛"；加购部分用单独的商品毛利参数。

### 4.4 子模型③：转化响应

```text
L = Σᵢ wᵢ × [该类型的流失概率]    R = 1 − L
s⁺ = min(k × F/T, s_max)
ΔC⁺ = min((1 − C₀) × e⁺, C₀ × s⁺ × e⁺)
最终转化率 C = C₀ × R + ΔC⁺
净转化变化 ΔC = ΔC⁺ − C₀ × L
```

e⁺ 是基准非购买者中的有效触达比例，不必等于 eᵢ；N 已限定为全部实际触达者时相应 e 设 1（避免重复折算）。s⁺ 是**毛新增相对 C₀ 的情景增幅**，不等于实验净转化提升；历史数据给净变化 ΔC 时按 `ΔC⁺ = ΔC + C₀L` 对账，超出可行范围要提示模型与证据不相容，不能强行截断。C₀=0 时相对响应曲线无法产生新增成交，只能用有来源或显式假设的绝对 ΔC⁺。

新增成交用单独结果分布 vⱼ（Σvⱼ=1）：`新增订单数 = N × ΔC⁺`，`新增贡献 = N × ΔC⁺ × Σⱼ[vⱼ × π_new,ⱼ]`。vⱼ 已是归一化结果分布，不能再乘基准 P₁ 或平均凑单率；不能默认新增人群篮子/成本/核销率与原有人群相同；跨候选比较时新增篮子分布随门槛变化的方式必须显式说明（本方案合成案例 B=T 仅用于演算；实际寻优需对新增篮子结构和可达性单独做压力检查）。

### 4.5 子模型④：统一收益账本

```text
本次券前商品毛利 G(B|A) = A × m_base + (B − A) × m_addon
客户商品实付 P_customer = B − uF
平台券补偿 S_platform = u(1 − ρ)F
商家券承担 S_merchant = uρF
单笔贡献 π(B,u|A) = G(B|A) − S_merchant − V(B,u) − H(B,u)
```

V 为未含在商品毛利中的可变费用（可配置为 固定履约费用 + 费率×P_customer；平台按不同金额基数收费必须显式配置）。H 为退货等结算路径相对"无退货贡献"的期望净减少额（须已考虑应退收入、可回收货品成本、补贴冲回与不可回收费用；不能在 H 外再次扣同一笔退货损失；首期仅汇总假设时显示"退货调整为情景估计"）。新增成交用自身券前商品毛利 G_new(B)，不得把新增订单当"旧篮子的加购部分"。

统一期望账本（每个成交分支记录：人群类型/基准篮子/结果分支/概率/期望订单数/券前商品金额/客户实付/核销数量/商家券补/平台券补/商品毛利/可变费用/退货调整/贡献收益）：

```text
Π_base_after = N × C₀ × Σᵢ wᵢ × Σₕ[pᵢₕ × πᵢₕ]
Π_new = N × ΔC⁺ × Σⱼ[vⱼ × π_new,ⱼ]
Π_coupon = Π_base_after + Π_new − K
Π₀ = N × C₀ × Σᵢ[wᵢ × π₀,ᵢ]
ΔΠ = Π_coupon − Π₀
```

K 只含相对无券方案新增的固定活动费用（基准已承担的固定费用不再扣）。同一账本同时汇总：订单数 O = N×C₀×R + N×ΔC⁺；转化率 C = O/N；GMV_pre = Σ[分支期望订单数×B]；GMV_paid = Σ[分支期望订单数×(B−uF)]；商家券成本 B_m = Σ[uρF]；平台券成本 B_p = Σ[u(1−ρ)F]。GMV_pre 不能称客户实付；未扣退款金额不能称净结算收入。

### 4.6 必须展示的贡献拆解（与总 ΔΠ 对平）

```text
增量贡献 = 自然核销订单的贡献变化
         + 加购订单相对原篮子的贡献变化
         + 其他保留成交的贡献变化
         − 流失订单原本贡献的损失
         + 新增成交的贡献
         − 新增固定活动费用
```

解释层只能引用账本中已有值，不允许为生成"好听的理由"重新算数。

## 五、L3 决策层

- **候选生成**：历史分位数 + 人工指定门槛 + 面额档位 + 业务禁止项合并去重，按真实金额计算。每次都加入 `enabled=false` 无券候选（直接使用完整基准，不是"门槛为零仍跑转化响应公式"）。不默认把 F/T 某固定区间当安全证明；折扣上限可配置为业务规则但不得输出"低于 20% 不会套利/超过 20% 必然套利"。
- **三种业务模式**：毛利优先（最大化 ΔΠ，券后贡献口径，转化与预算可设上下限）；转化优先（最大化 C 或 ΔC，默认 ΔΠ≥0；"GMV 优先"单独可选指标不与转化混称）；均衡模式（多目标非支配集合，业务选择；需要单一分数时用固定业务尺度归一化：`Score = w_profit×(ΔΠ/profit_scale) + w_conversion×(ΔC/conversion_scale)`，尺度/权重/方向存入场景，不同单位指标不直接相加，不因临时极端候选自动改变归一化尺度）。
- **约束与降级**：增量贡献底线默认 ΔΠ≥0，受控亏损须主动开启+设最大损失+醒目标记；商家券预算对 B_m 检查（平台补贴另列，可同时检查压力情景预算）；转化/GMV 目标必须明确指标、绝对变化或相对变化（相对提升与百分点分开显示）；单笔或分组贡献底线（不能总体均值掩盖特定价格带亏损）；净增量 ROI = ΔΠ/B_m（B_m=0 返回"不适用"，不除零不伪造无限收益）；券规则合法性 0<F<T（复杂规则阻断）；参数与数据质量未知可做情景但不能自动提升为已验证推荐。预算是**预估与过滤约束，不是投放限额执行器**——超预算结果标不可行，不能截断成本保留收益。
- **四类结论**（不是每次都输出冠军）：可行候选（列证据状态）；需小范围验证（有潜在收益但关键参数缺适用证据）；建议不发券/无可行券方案（无券本身也不满足业务目标时写"当前候选与约束下无可行解"）；无法形成有效比较（口径冲突或输入不合法，先修复输入）。每个被选方案同时展示邻近门槛与面额方案；相邻方案被过滤时显示过滤原因，不能从界面消失。"推荐"只能解释为当前候选集合/模型结构/参数/约束下的**条件性建议**。

## 六、敏感性、盈亏平衡与风险解释

```text
回本所需毛新增成交率 ΔC⁺_BE = max(0, (Π₀ + K − Π_base_after) / (N × π̄_new))
C_BE = C₀ × R + ΔC⁺_BE
ΔC_BE = C_BE − C₀
```

必须检查 ΔC⁺_BE 是否超过可触达非购买者上限（超过标"当前假设下不可回本"）；重算该新增量对应补贴预算。π̄_new ≤ 0 时提示新增成交贡献非正，不能把"再多拉新订单"当通用解。改变转化同时改变篮子/渠道/库存/预算截断/核销率时上式不再直接适用，逐情景重跑。

必做敏感性（P0 至少）：新增转化响应、凑单概率、失败流失、加购商品毛利、核销率、券承担比例；数据场景不匹配时加客单结构变化。支持单因素与"保守/基准/积极"联合情景；变化范围由用户指定或可说明估计，不内置固定 ±20%。输出至少：各情景 ΔΠ、预算是否超限、排序是否变化、所选方案是否仍可行、主要敏感参数。

区间不混称：情景范围（所设参数组合的结果范围）≠ 压力情景（人工构造困难条件，无发生概率）≠ 统计区间（需样本与估计程序，附方法）。不生成收益成功概率、星级置信度、伪精确 95% 区间；仅一组参数时不把相邻券微小收益差当稳健优势。

不从模型强推结论：面额增大是否有利取决于核销成本/加购/转化响应；门槛收益是否先升后降取决于行为与商品结构；"所有基准订单未自然达标"≠退化为无券（仍可能加购/新增/流失）。

## 七、可复现合成案例（新版黄金值）

**输入**：N=100,000；C₀=8%；基准篮子金额分布（无券成交订单权重）：A=60/90/110/140/190 元 → w=20%/20%/30%/20%/10%（均值 110 元，基准订单数 8,000）；无券总贡献 = 100,000×8%×110×30% = 264,000 元。

其他假设：商家承担全部券补（ρ=1）；原篮子/加购/新增商品毛利率均 30%；基准与新增人群有效触达比例均 1；自然核销率 r=80%；加购核销率 r⁺=100%；q_cap=0.8、λ=2.2、d_ref=0.1；流失率 d=2%；k=0.9、s_max=0.5；加购后金额取 T；所有新增成交以 T 为商品金额并核销；不计其他费用、退货和新增固定成本。

## 九、参数证据与活动复盘

- `ParameterProfile` 至少含：参数名/值/单位/来源类型/来源说明/适用活动/人群/品类/渠道/有效时间/样本规模或依据/估计方法/不确定性说明/创建时间/版本/人工确认记录。来源类型区分：业务输入、合成演示、历史描述估计、观察性建模、对照/实验支持（不是可相加的证据分数）。
